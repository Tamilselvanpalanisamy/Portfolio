## Run Locally

Open `index.html` in a browser, or use a local server:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000`

## Deploy

Push to GitHub and enable **GitHub Pages** (Settings → Pages → deploy from `main` branch).
